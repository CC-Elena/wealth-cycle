# Spec: 预算动态调剂规则

## 新增需求 (ADDED Requirements)

- 系统应能基于当前周期的已过时间比例与已消费比例的偏离度，识别“高风险”与“冗余”预算块。
- **关联场景**: 识别风险
  - **GIVEN**: 用户设有 2000 元饮食预算，本月共 30 天
  - **WHEN**: 到了第 10 天，已消费 1000 元 (50%)
  - **THEN**: 系统应将该预算标记为红色风险等级

- 系统应支持 Agent 发起的跨预算块资金划转，且该操作必须在用户确认后执行。
- **关联场景**: 实施调剂
  - **GIVEN**: 饮食预算已超标预警，购物预算预测结余 500 元
  - **WHEN**: 用户同意 Agent 的调剂建议
  - **THEN**: 饮食预算增加 200 元，购物预算减少 200 元，并生成调剂记录
