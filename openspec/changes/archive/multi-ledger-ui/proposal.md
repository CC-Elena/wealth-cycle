# Proposal: Multi-Ledger Management UI (M9-L2)

## 1. 背景与目标 (Background & Goals)
目前项目已在后端 Service 层和数据库 Schema 层面实现了 `ledgerId` 的逻辑隔离，并且前端 `financeStore` 也初步具备了处理 `currentLedgerId` 的能力。
但是，用户界面上仍然缺乏管理这些账本的入口。

本变更的目标是：
- 在 **Profile (我的)** 页面增加“账本管理”入口。
- 实现 **Ledger Management** 页面，展示所有账本及其核心统计（如净资产）。
- 支持 **切换账本**：点击即切换全局上下文。
- 支持 **创建账本**：允许用户通过对话或手动表单创建新的独立账本（如“工作独立账本”）。

## 2. 核心价值 (Core Value)
- **多维度管理**：真正实现生活与工作财务的物理+逻辑双重隔离。
- **全栈闭环**：完成多账本支持的最后一块拼图——用户交互层。

## 3. 验收标准 (Success Criteria)
- 用户可以在“我的”页面看到当前活跃账本名称。
- 点击可进入账本列表。
- 在列表中选择另一账本后，Dashboard、流水、分析等所有数据立即同步刷新。
- 可以创建新账本并立即切换至该账本。
