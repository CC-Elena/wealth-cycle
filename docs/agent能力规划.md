# TwinLedger Agent 能力规划书

## 一、 核心愿景
**目标**：消除记账的枯燥感、降低决策的认知负担、并提供具有“防御性”的财务保护。
**原则**：隐私优先、交互极简、主动反馈、赋能决策。

---

## 二、 能力模块分解

### 1. 交互录入层 (Frictionless Input)
旨在将录入成本降至最低。

#### 1.1 语义自动分类与拆单 (Smart Categorization)
- **描述**：识别自然语言（文本或语音转文字）中的消费意图。
- **能力点**：
    - 自动识别“金额、分类、备注、支付方式”。
    - **拆单支持**：识别复合消费（如“超市花了200，买了菜和洗发水”），自动按比例拆分为多条交易。
- **用户价值**：极致的精准度与极低的参与成本。

#### 1.2 外部账单静默处理 (Log Processor)
- **描述**：解析用户复制的微信/支付宝账单文本。
- **能力点**：批量识别、查重过滤、自动补全缺失信息。

---

### 2. 智能洞察层 (Intelligent Insight)
旨在将冰冷的数据转化为有温度的建议。

#### 2.1 财务健康诊断 (Health Narrator)
- **描述**：对“生存天数”和“净资产”进行场景化解读。
- **能力点**：
    - **生存天数解读**：不仅仅是数字，而是结合历史频率的风险评估（例如：“按目前速度，你撑不到月底”）。
    - **周期总结**：生成月度消费摘要，自动识别异常高额支出和显著浪费项。
- **用户价值**：让数字具备指导意义，提供情绪价值。

#### 2.2 风险警报器 (Anomaly Detection)
- **描述**：识别非日常、高频率或高额的异常消费。
- **能力点**：
    - 识别突发的“非必要支出”并弹出确认界面。
    - 监控分类预算耗尽风险，提前干预。

---

### 3. 主动决策层 (Behavioral Nudge)
旨在通过 Agent 介入，改变用户的财务行为。

#### 3.1 动态预算调度 (Fluid Budgeter)
- **描述**：打破僵化的预算限制。
- **能力点**：发现 A 分类盈余而 B 分类超支时，主动提议挪用资金（例如：“交通省了200，要挪给聚餐吗？”）。
- **用户价值**：让预算管理变得灵活、包容，减少超支挫败感。

#### 3.2 购物冷静期谈判员 (The Negotiator)
- **描述**：阻断冲动消费。
- **能力点**：
    - 对预购项目进行 3-5 维度评分（单价占比、历史利用率、生存天数缩短值等）。
    - 强制/建议进入“冷静期”，到期后再询问购买意向。
- **用户价值**：理性的“另一个自我”，提供防御性财务保护。

## 三、 实施阶段规划

### 第一阶段：MVP 提效 (Phase 1)
- **重点**：实现“智能录入”与“健康解读”。
- **目标**：让用户感受到“记账变容易了，数据变清晰了”。
- **功能**：语义分类、生存天数场景化解释、月度摘要。

### 第二阶段：主动管理 (Phase 2)
- **重点**：实现“异常监控”与“预算调度”。
- **目标**：让用户感受到应用在“看守”自己的钱包。
- **功能**：高额消费提醒、分类盈余挪用建议。

### 第三阶段：行为重塑 (Phase 3)
- **重点**：实现“预购拦截”与“跨周期预测”。
- **目标**：通过极致的行为干预大幅提升用户的资产净值。
- **功能**：冷静期谈判、库存联动分析。

---

## 四、 技术实现原则 (Technical Design)
1. **Tool-Integrated LLM**：LLM 必须具备调用系统 API 的能力（如读取当前预算、写入交易）。
2. **Context Injection**：每次对话必须携带用户的财务上下文（预算余额、可支配资金、分类列表）。
3. **Structured Output**：LLM 必须强制输出 JSON 格式，以便系统逻辑精准解析。
4. **Local-First Buffer**：所有的 Agent 提议必须经过用户手动点击确认后，方可写入物理数据库（权限隔离）。
