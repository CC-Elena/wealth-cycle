
- **消费智能分类 Agent**
    - 自动识别账单描述，归类到餐饮 / 交通 / 购物等
    - 自动标记必要 / 非必要消费
- **预算智能分配 Agent**
    - 根据收入、历史消费、储蓄目标自动做预算分配
    - 动态调整超支类目，保持整体平衡
- **库存 & 防重复购买决策 Agent**
    - 查询现有物品库存、消耗速度
    - 判断是否需要补货、是否重复购买
- **预购决策顾问 Agent**
    - 查询预算、月度余额、储蓄进度
    - 给出 “建议买 / 冷静 7 天 / 不建议买” 的决策理由
- **储蓄目标执行 Agent**
    - 自动计算每月需存金额
    - 从消费中挖掘可优化空间，推进目标
- **月度财务健康分析 Agent**
    - 自动生成财务报告、风险点、优化建议
    - 识别浪费、闲置订阅、冲动消费
- **现金流预警 Agent**
    - 预测发薪前是否会缺钱
    - 提前提醒削减非必要支出
