
## 技术栈设计

### 项目概述

全周期个人财务管理 Web/H5 应用，通过收入、预算、消费、库存、储蓄、预购决策形成财务闭环，并内置财务智能体（Financial Agent）。采用前后端分离架构，pnpm Monorepo 统一管理，一套代码响应式适配桌面端和移动端。

### 响应式适配策略

一套代码，通过 Tailwind 断点 + 条件渲染适配三种视口：

| 视口 | 断点 | 导航方式 | 布局 |
|---|---|---|---|
| 桌面端 | `lg` (1024px+) | 左侧固定 Sidebar | 多列布局，Dashboard 卡片网格 |
| 平板端 | `md` (768px-1023px) | 可折叠 Sidebar | 双列/单列自适应 |
| 移动端 | `sm` (<768px) | 底部 TabBar | 全屏单列，Sheet 替代 Dialog |

关键组件适配模式：
- **导航**：桌面 `Sidebar` ↔ 移动 `TabBar`（条件渲染）
- **弹窗**：桌面 `Dialog` ↔ 移动 `Sheet/Drawer`（封装统一的 `ResponsiveModal`）
- **列表**：桌面 `Table` ↔ 移动 `Card List`（通过 `useMediaQuery` 切换）
- **表单**：统一使用 React Hook Form，布局通过 Tailwind grid 断点适配

### 前后端数据流

```
用户操作 → React 组件
              ↓
         TanStack Query (useMutation)
              ↓
         ky.post('/api/transactions', { json: data })
              ↓ HTTP
         NestJS Controller（DTO 校验 via Zod）
              ↓
         NestJS Service（业务逻辑）
              ↓
         Drizzle ORM → 本地 SQLCipher加密 / 云端 PostgreSQL脱敏存储
              ↓
         EventEmitter.emit('transaction.created', payload)  ← Agent 可订阅
              ↓
         返回 Response
              ↓
         TanStack Query 自动更新缓存
              ↓
         React 组件重新渲染
```

### Zod Schema 共享示例

```typescript
// packages/shared/src/schemas/transaction.schema.ts
import { z } from 'zod';

export const TransactionSchema = z.object({
  amount: z.number().positive(),
  categoryId: z.string().min(1),
  type: z.enum(['income', 'expense', 'refund', 'budget_overflow']),
  memo: z.string().optional(),
  tags: z.array(z.string()).default([]),
  date: z.string().datetime(),
});

export type Transaction = z.infer<typeof TransactionSchema>;

// 前端用：React Hook Form 的 resolver
// 后端用：NestJS Pipe 的 validate
// 两端共享同一份校验规则，零重复
```

### Agent 预留架构

| 端点 | 方法 | 用途 |
|---|---|---|
| `/api/agent/context` | GET | 返回用户当前财务状态摘要（预算余额、库存警告、储蓄进度等），供 Agent 推理 |
| `/api/agent/tools` | GET | 返回所有可用业务操作的 OpenAPI schema，可直接转化为 function calling tools |
| `/api/agent/execute` | POST | 接收 Agent 的 tool call 请求，路由到对应 service 方法执行 |

事件系统：
- 所有业务操作通过 `@nestjs/event-emitter` 产生事件
- 事件类型：`transaction.created`、`budget.exceeded`、`inventory.expiring`、`payroll.processed` 等
- Agent 可订阅事件做主动推送（如预算超支自动提醒）

后续可将整个后端包装为 MCP Server，让外部 Agent 直接调用。

### 后端安全与基础架构拓展

遵循“最小云化”与“隐私优先”原则，后端基础内容拓展如下：
1. **端侧存储与加密**：以 SQLCipher 为基础提供本地加密数据库，账号/设备/本地 DB 密钥分层隔离，确保数据本地安全闭环。
2. **端云脱敏同步机制**：建立健全的 Sync 服务。云端拒绝存储流水级完整明细及其生活记录，所有上云数据必须经过端侧重度脱敏及聚合计算。
3. **数据主权**：强制应用全量 HTTPS/TLS 加密通信，并内置数据全量导出及远程“一键抹除”功能。

### 实施阶段

1. **Monorepo 骨架**：pnpm workspace + 三个 package 初始化 + TypeScript 配置
2. **前端初始化**：Vite + React + Biome + Tailwind v4 + shadcn/ui + 响应式 Layout
3. **后端骨架提升**：NestJS + Drizzle + SQLCipher加密DB层集成 + 端云 Sync 机制 + Swagger
4. **共享包 + 联调**：Zod schemas + ky API 层 + TanStack Query hooks
5. **Agent 预留**：AgentModule + EventEmitter + context/tools 端点
